## Building & Releasing

- Make a **Release** build, not a Debug build.
- Publish **self-contained** so players don't need to install .NET.
- Test the build on a machine (or a clean folder) that has never run your game.
- Upload a Windows build to [itch.io](https://itch.io).

## Finalizing Your Game

Prioritize what makes the game feel finished:

- A title screen, a way to win or lose, and a way to restart.
- Sound and music.
- No crashes on the common paths.

Cut features before you cut polish.
