## Books

- Robert Nystrom, [_Game Programming Patterns_](https://gameprogrammingpatterns.com/).
  Free to read online. The course uses several chapters from this book.
- Jason Gregory, _Game Engine Architecture_.

## Documentation

- [MonoGame Documentation](https://docs.monogame.net/): Documentation, API reference, guides
  and tutorials used in the course.
- [Building 2D Games](https://docs.monogame.net/articles/tutorials/building_2d_games/):
  The MonoGame tutorial series the sessions draw on.

## Articles

- Glenn Fiedler, [Fix Your Timestep!](https://gafferongames.com/post/fix_your_timestep/)
- [Architecture, Performance, and Games](https://gameprogrammingpatterns.com/architecture-performance-and-games.html)
- [MonoGame Components and Services](https://gavsdevblog.wordpress.com/2016/09/04/monogame-components-and-services/)

## Tools & inspiration

- [bfxr.net](https://www.bfxr.net/) — make your own 8-bit style sound effects.
- [Interface in Games](https://interfaceingame.com/games/) — examples of good game UI.
