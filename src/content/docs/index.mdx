**GAR** is a course about software design and architecture in game development. We build
twelve classic games in C# and MonoGame, one per session. The first is a naive Pong written
in a single class, and the last is a Vampire Survivors-style game with thousands of enemies.
Each game brings a design problem that the one before didn't have, and the patterns that
solve it.

## GARCore

Throughout the course, reusable code moves from the individual games into **GARCore**, a
shared class library that grows into a small game framework with screen scaling, input,
sprites, animation, tilemaps, state machines and more. Deciding what belongs in the core and
what belongs in the game is an architectural decision in itself, and we make it again every
session.
