Welcome to the course website for **GAR** (Game Architecture), a course about **software
design and architecture in the context of game development**. We build twelve
classic games in MonoGame, one per session, starting with a naive but working Pong and
ending with a Vampire Survivors-style game that handles thousands of enemies. Along the
way, each game introduces the patterns and design principles that keep a growing game
manageable.

Use the sidebar to navigate through the course. The [schedule](schedule/) gives an
overview of all sessions, the [exam](exam/) page lists every exam question together with
the sessions that cover it, and the [course recap](recap/) shows where every pattern
appears.

## GARCore

Throughout the course, reusable code moves from the individual games into **GARCore**, a
shared class library that grows into a small game framework with screen scaling, input,
sprites, animation, tilemaps, state machines and more. Deciding what belongs in the core and
what belongs in the game is an architectural decision in itself, and we make it again every
session.
