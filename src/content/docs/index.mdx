Welcome to the course website for **GAR** (Game Architecture). This course explores
**software design and architecture in the context of game development**. We build seven
classic games in MonoGame, starting with a naive but working Pong and ending with a
Geometry Wars clone that handles thousands of entities. Along the way, each game introduces
the game programming patterns and design principles needed to keep a growing game robust
and maintainable.

Use the sidebar to navigate through the course. The [schedule](schedule/) gives an
overview of all sessions, and the [exam](exam/) page lists every exam question together
with the sessions that cover it.

## GMDCore

Throughout the course, reusable code moves from the individual games into **GMDCore**, a
shared class library that grows into a small game framework: screen scaling, input, sprites,
animation, tilemaps, state machines and more. Deciding what belongs in the core and what
belongs in the game is itself an architectural decision, and one we return to every
session.
